# Little Boxes

A browser puzzle about rotating and nesting boxes in twenty handcrafted arrangements.

[Play Little Boxes](https://boxes.burritoslabs.com/)

## Technology

HTML, CSS, JavaScript, SVG and Service Worker.

## Architecture

The puzzle rules check placement and orientation separately from the SVG presentation. Pointer, touch and keyboard operations act on the same puzzle state.

## Product behavior

Progress stays in the browser. Offline play is available on supported browsers once the game reports it is ready.
